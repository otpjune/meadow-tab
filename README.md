# 🌿 Meadow Tab

A calm Chrome new tab page: big clock, frosted-glass search with suggestions, focus timer and app-style shortcuts.

This repo has two extensions:
- **meadow-tab**: the new tab page
- **meadow-frame-theme**: a dark green Chrome theme to match (optional)

## Install

1. Click the green **Code** button above, then **Download ZIP**.
2. Unzip the downloaded file.
3. Open `chrome://extensions` in Chrome.
4. Turn on **Developer mode** (top right).
5. Click **Load unpacked** and choose the `meadow-tab` folder.
6. (Optional) Click **Load unpacked** again and choose the `meadow-frame-theme` folder for the green browser frame.
7. Open a new tab and enjoy!

## Tips

- Right-click a shortcut to edit or remove it. Click **+** to add one.
- Click the **...** button (top right) to change the background.
- Chrome keeps the cursor in the address bar on new tabs, so click the search bar to type in it.
