MEADOW TAB — install steps
1. Unzip this file.
2. Open chrome://extensions and turn on "Developer mode" (top right).
3. Click "Load unpacked" and choose the "meadow-tab" folder. (Do the same with "meadow-frame-theme" for the green browser frame.)
4. Open a new tab.

Tips
- Right-click a shortcut to edit or remove it. Click "+" to add one.
- Click the "..." button (top right) to change the background.
- Chrome keeps the cursor in the address bar on new tabs, so click the search bar to type in it.
